# Caballero

Juego de plataformas 2D en pixel art hecho con Godot 4.
Un caballero recorre el mundo para rescatar a su mejor amigo de la infancia.

> Versión inicial: por ahora solo hay movimiento, doble salto y un escenario de prueba.

## Controles

| Acción | Tecla |
|---|---|
| Moverse | Flecha izquierda / Flecha derecha |
| Saltar | Barra espaciadora |
| Doble salto | Barra espaciadora otra vez, en el aire |
| Correr | Mantener Shift mientras te mueves |

## Cómo jugar

1. Entra a la sección **Releases** de este repositorio.
2. Descarga `caballero.exe`.
3. Ábrelo con doble clic. Si Windows muestra un aviso de SmartScreen, toca **Más información > Ejecutar de todas formas**.

## Hecho con

- Godot 4.7
- LibreSprite (arte en píxeles)
